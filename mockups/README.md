# Mockups

Standalone design mockups (React + Tailwind from CDNs, sample data). None of these files are loaded by the app, and nothing in them saves anything. Open a file in a browser, full screen. They need an internet connection for the CDN scripts.

| File | What it is | Status |
|---|---|---|
| `brain/index.html` | Brain and node looks above the approved dock; "brain" buttons at the bottom right switch looks | **Approved: brain look 6 + dock "instrument"** (the page's defaults; CLAUDE.md, Phases 18 and 19) |

The older dock, capture-card, task-card, footer and redesign mockups were deleted 2026-11-22 (they live in git history).

`brain/STATES.md` lists every view for Phases 18 and 19 (Step 0); the "view" control at the bottom left of `brain/index.html` jumps into each one.

In `brain/index.html` the brain looks are: 1 hologram, 2 core scan, 3 core scan + circles, 4 hologram + core, 5 connected, 6 richer nodes (approved), and "old" (a screenshot of the app as it was on 2026-11-10). The "dock" buttons switch between "instrument" (approved) and "as approved" (the earlier styling).
